# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 黄金窗曲线册

逆变器启动后的十分钟叫黄金窗，顶栏"黄金窗专页"分三区：

- **窗名区**：开窗/关窗时刻与倒计时；有写权限的扫描员填窗名按"封存"，观察员只看到只读提示。
- **轨迹区**：此刻在途（pending）各串读数，两秒刷新。
- **查阅区**：已封曲线册，空着显示"还没有曲线"；点开任一册可翻阅当时抄录的点列，观察员同样可翻。

规则：

- 封存把此刻**全部在途各串读数原样抄录**进新曲线册（独立快照表），封存后即使在线单办结，旧册内容也刮不掉。
- 册名与点列在**同一个数据库事务**写入：窗名为空、此刻无在途、或已过黄金窗都会整体回滚；另设延迟约束触发器，没有点列的册在提交时被数据库拒绝——缺一边整页不算完工。
- 封存瞬间对在途单加行锁，与工人办结互斥，不会漏抄或抄到半成品。
- 逆变器启动时刻只在首次写库时钉住（`app_meta.inverter_booted_at`），后端或容器重启不重开黄金窗。

接口：`GET /api/golden/state`（登录可见）、`GET /api/golden/albums/{id}`（登录可见，观察员可翻旧册）、`POST /api/golden/seal`（仅 writer 且窗内）。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`
